# k8s-cost-governor

Kubernetes 资源与成本治理工具：识别闲置资源、生成 right-sizing 建议、
输出可量化的成本分析报告。

**状态：开发中** — 预计 2026 年 10 月下旬可用

---

## 解决什么问题

K8s 集群里最常见的成本浪费不是"用得多"，而是"要得多用得少"——
资源 requests 远高于实际用量、长期空转的工作负载持续占用配额。
这类问题靠人工翻监控很难系统发现，靠账单又看不出归因。

本工具从集群侧采集资源声明与实际用量，做差异分析，直接给出可执行的调整建议。

## 计划能力

- [ ] 采集集群资源声明（requests / limits）与实际用量
- [ ] 识别闲置与过度申请的工作负载
- [ ] 生成 right-sizing 建议与预估节省
- [ ] 输出成本分析报告（图表 + 结论）
- [ ] CLI 封装，支持多集群、多命名空间

## 技术栈

Python · kubernetes-client · kopf · Prometheus API · pandas · matplotlib · typer
代码质量：ruff + mypy + pytest
